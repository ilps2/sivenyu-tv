从本地成功实现移植 BootGateActivity、BootStart 和启动策略，加入仅 MiTV-MTSU0 可启用的保护，默认关闭。保留普通应用入口与原 Home 行为；右下角设置新增桌面选项，电视系统设置在同一面板内。

原理是小米 `start_3rd_app` 配置调用包的 INFO 入口，每次完整启动最多进入一次。没有新增权限、开机广播接收器、无障碍服务或常驻服务。系统设置仅在用户按文档配置时写入，应用不自动修改。

更新 README、完整指南、兼容性说明及专门的启用/关闭/恢复文档；提醒系统可能缓存目标，不能在仍配置开机目标时直接降级到无判断入口的旧版。

私人同源实现已在 MiTV-MTSU0 / OS3.0.119.0.UTSMATV 上通过完整重启、Home、重复调用不抢占 HDMI、开关关闭/开启验证。公开 APK 的整套重启验证未执行；没有将私人测试冒充公开签名包的实机结果。

公开版仅保留此前已授权的五张 Unsplash 图片。私人照片、系统 APK、反汇编材料、设备地址、日志、调试密钥和签名文件不进入仓库或安装包。
