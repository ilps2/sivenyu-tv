## 范围

从已实机使用的个人定制版本提取列表桌面、壁纸轮播与小米接口，整理为可独立构建的 Android 工程。保留右下角操作区及 HDMI 直接入口。

公开版使用独立包名 `io.github.op7418.sivenyutv` 和独立发布签名，不覆盖私人版本或上游应用，不自动迁移偏好。保留 Gathin 的 MIT 版权声明，并注明 CleanFrame 的设计参考。

私人照片替换为源码绘制的五种渐变，提供本地壁纸打包脚本。用户原图不变，旧的生成素材移出 assets 并保留备份，避免旧图进入后续 APK。签名、密码、设备地址、截图及诊断日志未加入公开仓库。

公开工程没有原项目的清理脚本、旧 Dock、无障碍按键服务、字体二进制或系统应用禁用流程。其余私人源码与安装包保留在本地，没有覆盖。

## CI 环境修正

首次 GitHub Actions 在 SDK 准备阶段失败：setup-android 的默认包列表包含已不可用的 `tools`。
改为明确只准备 `platform-tools`，编译所需的 Platform 34 / Build Tools 34.0.0 仍由后续步骤安装。
此修正只影响 CI，不改变已验证并发布的 APK。
