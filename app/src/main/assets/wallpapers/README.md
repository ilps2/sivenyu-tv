# 壁纸资源

公开版默认打包九张壁纸：`generated/` 下的纯黑、纯蓝、天空蓝、玻璃海，
以及 `bundled/` 下原有五张 Unsplash 照片，每 5 分钟轮播。
新安装从纯黑开始；覆盖更新按已保存的壁纸 ID 保留原选择和移除记录。
来源与校验值见 `catalog.json`；生成素材说明见 `generated/GENERATED-NOTICE.md`，
Unsplash 照片许可见 `UNSPLASH-NOTICE.txt`。
目录为空时，应用自动回退到五种源码绘制的渐变背景。

自行打包照片请使用项目根目录的 `scripts/prepare_wallpapers.py`。
它将图片和目录写入被 Git 忽略的 `local/`，应用优先读取这个目录。
原图不变；生成副本去除 EXIF、最长边 1920 像素，缩略图 320 × 180。
内置三张纯色保留 3840 × 2160 原始 PNG；玻璃海保留 1672 × 941 原始 PNG，
没有放大或标为 4K。运行时内置壁纸按最长边不超过 1920 像素采样解码，
避免电视为每张 4K 纯色图分配约 32 MiB 位图；列表使用独立缩略图。
不要公开发布自己没有再分发权的照片或包含私人信息的素材。
