# 应用安装信息

「应用」管理页的每张卡片显示安装日期与时间；焦点移到应用时，下方显示应用名、
版本、首次安装时间、最近更新时间和完整包名。日期按电视本机时区显示，精确到分钟。

页面上方始终显示「当前正在使用」的桌面名称、版本、安装时间、更新时间及包名，
可与同名旧包对照。当前桌面仍不加入可选应用网格，也不允许从本页标记卸载自己。

数据来自 Android PackageManager 的 firstInstallTime、lastUpdateTime 和 versionName，
随应用列表在工作线程读取，不需要存储或额外权限。缺失信息显示「未知」。
覆盖安装保留首次安装时间，最近更新时间会变化；重新卸载再安装会产生新的首次安装时间。
本功能不依据日期自动选择、隐藏或删除任何应用，卸载仍由用户标记并经系统确认。
