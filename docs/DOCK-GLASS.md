# Dock 玻璃焦点

设计方向参考 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 的半透明控制层与流动感，在 Android 电视上自行绘制，不调用 Apple 系统材质。

## 形状与交互

- 一颗共享胶囊位于四个文字按钮后方，常态无永久条状背板。
- 使用连续曲线端部，直线连接处的曲率从零开始；主体、高光与内外边缘均沿同一族 Path 绘制，避免矩形高光裁剪。
- 按钮最小尺寸 104×48dp，字号 17sp；聚焦时不改字体和缩放，系统大字模式仍可自然扩展尺寸。
- 胶囊随焦点在 260ms 内平移或改变宽度，快速连续按键会从当前位置继续；离开 Dock 约 150ms 淡出。
- 系统关闭动画时直接切换位置。文字始终独立于玻璃，保持清晰。

## 材质与开销

- 最长边不超过 256px 的缓存只绘制壁纸 ImageView 和它的暗化层，不捕获应用、文字、菜单或屏保。
- 缓存进行两轮半径 2px 的可分离方框模糊。胶囊通过屏幕坐标采样缓存，并做 1.035 倍轻微放大，模拟透射厚度。
- 叠加低透明度亮膜、上下渐变、对向边缘高光、内圈反射与软化阴影。
- 换壁纸的淡入完成、构图改变或布局改变时合并刷新缓存。焦点动画期间只改变几何与采样矩阵，不逐帧截屏或重新模糊。
- 缓存不可用时保留半透明亮膜与边缘；组件离开视图树时取消动画、移除回调并释放缓存引用。
- 这是兼容 Android 8/9 的视觉近似，未实现 Apple 的原生材质或实时物理折射。壁纸淡入期间继续使用上一次缓存，在淡入结束后更新。

本地设计图是使用同样轮廓参数与分层颜色生成的 SVG 预览，不是 Android 或电视截图；遥控器响应、设备 GPU 绘制与材质观感仍需实机确认。
