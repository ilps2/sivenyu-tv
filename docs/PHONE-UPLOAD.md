# 手机端长按取消上传

手机扫码打开上传网页后，每个文件有独立的「长按取消」按钮：

- 按住约 0.7 秒确认取消，按住时显示进度；提前松开、滑动或页面失去焦点会撤销这次长按。
- 等待中的文件直接从发送队列取消；正在发送的文件先中断 XMLHttpRequest，再携带本会话令牌与文件请求 ID 向电视确认取消结果。
- 如果电视已经接收完整文件，返回「已接收完成，文件已保留」，不会把已入库文件误报为已删除。
- 多文件按顺序发送，当前取消确认完成后才发送下一个，避免取消确认被下一笔大文件阻塞。
- 传输先写入私有 `.uploads/*.part`，完整接收后再移动到媒体目录；异常、取消或关闭电视上传窗口会清理未完成临时文件。关闭窗口同时关闭正在处理的连接。
- 每次会话仍有原有的单文件 200MB、累计 2GB 上限；最多记录 256 个请求 ID，避免取消记录无限增长。需更多文件时重新打开电视上传窗口。
- 文件名和状态均使用 textContent 展示，不作为 HTML 执行；会话令牌仅注入本次页面。

电视窗口保留「完成」，并整合正式版已有的整场取消入口：「长按取消本次上传」。
遥控器确认键按住约 700ms 停止本次服务并关闭连接，松手、移走焦点会撤销尚未触发的长按；
短按只显示操作提示。已完成文件保留，未完成暂存文件由接收线程清理。
取消后窗口显示已取消状态，关闭并重新扫码可创建新会话。手机端仍可单独取消某个文件。
