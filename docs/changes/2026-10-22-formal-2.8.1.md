# 2.8.1：统一正式包与内置资源

## 修正交付目标

此前液态玻璃、手机取消上传和四张新增壁纸只交付为独立预览包，
电视仍可能运行另一份不含改动的正式包。本次统一使用正式包名
`io.github.op7418.sivenyutv`，版本 `2.8.1-aptv` / code 236。
使用项目所有者本机既有签名配置覆盖，未清除数据或改变默认 Home。
签名配置不写入源码、文档或压缩包。

## 包含修改

- 默认目录新增纯黑、纯蓝、天空蓝与玻璃海，原五张 Unsplash 照片保留。
- 壁纸面板、屏保候选与未配置屏保时的默认轮播共用 catalog，尊重移除记录；
  已配置的屏保内容不自动改选。
- Dock 使用共享滑动镜片、连续曲率端部、壁纸模糊透射；主体 1.065 倍、
  边缘 1.14 倍采样形成折射差，暗化层降低至原强度的 176/255。
- 应用页显示首次安装日期，焦点详情显示更新时间、版本、完整包名；顶部标明当前桌面。
- 继续包含首页长按排序、两行等宽壁纸按钮、手机每文件长按取消和暂存文件清理。
- 整合另一处正式源码已做的电视整场取消入口，改为约 700ms 按住确认触发，
  取消关闭连接并保留完整文件，不保留原实现的直接写媒体目录方式。
