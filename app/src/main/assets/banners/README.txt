自定义横版图标（banner）
========================
尺寸：1280x768（5:3），PNG，无圆角、无投影（圆角由程序统一裁）
文件名：包名.png 或 应用中文名.png
示例：com.example.player.png / 播放器.png

本目录收录的横幅均为本项目自制，不含任何第三方产品商标或官方标识：
  io.github.op7418.aihotv.png      AIHOT电视端（米白底 + 深墨字标）
  com.yyw.box.androidclient.png    115 网盘
  com.quark.yun.tv.png            夸克网盘

其余应用的横幅请自行制作，或在运行期放入下列目录，无需重编。

运行期目录（优先级高于本目录）：
  U盘根目录/aptv-banners/包名.png
  Download/aptv-banners/包名.png

未提供横幅的应用会回退到「深色主色底 + 应用图标居中」的默认样式。
