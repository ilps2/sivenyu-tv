# 全屏音量提示

用户报告：红米 X65，型号 L65R8-X，使用电视内置扬声器。全屏桌面里音量可以调节，系统音量条不显示。
项目原有注释记录了音量键先被系统组件处理的现象，因此应用不能只依赖 `dispatchKeyEvent` 显示提示。

## 当前实现

- 保留现有全屏与隐藏状态栏的设置。
- 全屏页面在 `onResume` 后每 200 ms 读取 Android `STREAM_MUSIC` 的音量索引、最大值和静音状态。
- 读数发生变化时，在右下角显示百分比、进度条或静音提示，最后一次变化约 2 秒后隐藏。
- 首次打开、从其他应用返回、音频输出的音量范围改变时，先记录基准，避免把后台变化当成用户正在调音量。
- `onPause` 立即停止读取并隐藏提示，`onDestroy` 移除视图。没有常驻服务或系统悬浮窗。
- 应用不调用调音量接口。收到音量键时仍传给系统，避免重复调节，也避免用音量键关闭屏保。
- 默认开启；「设置 → 更多 → 音量提示」可以关闭，适用于已正常显示系统音量条的固件。

## 验证范围

`VolumeMonitorTest` 验证了没有任何按键事件时的音量变化、静音/取消静音、停止/恢复、不可读数据、音量范围变化和边界值。
代码构建与自动测试不能替代 L65R8-X 的遥控器和显示效果实测。

在电视上依次检查：

1. 从电视应用列表打开桌面，单按音量加/减；音量与提示同步改变，原状态栏保持隐藏。
2. 长按音量键；提示持续更新，松开约 2 秒后消失。静音与取消静音均有反馈。
3. 打开应用管理、壁纸页或应用内屏保，检查音量仍可调节，提示不抢遥控器焦点。
4. 切到其他 App，再返回桌面；其他 App 里不出现本桌面的提示，返回时不弹旧读数。
5. 在「设置 → 更多」关闭音量提示，调节后不再显示；重新开启后恢复。

## 限制

这是 Android 系统媒体音量索引的归一化百分比，不表示实际声压或外接功放面板数值。
HDMI ARC/eARC、固定音量输出或厂商私有音频通道若不向 Android 回传可读数值，无法保证显示反馈。
已经到达上限/下限后重复按键，若系统不向应用传递按键且数值不再改变，提示不会重新弹出。
系统 DreamService 屏保由系统管理，本次提示覆盖本应用的 Activity 页面。
